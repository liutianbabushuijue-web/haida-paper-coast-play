# 追潮记 · 拾光海岸

[去海边走走](https://liutianbabushuijue-web.github.io/haida-paper-coast-play/)

可以直接用电脑或手机浏览器登岛。图鉴保存在当前浏览器中。

**V17.0** 默认第一人称。按 V 或轻点视角按钮切换到第三人称，点击日奈可以看她回应。在岸边按 F 钓鱼，钓获后轻点或按键记录。按 Tab 翻开《追潮记》，可阅读鱼类、贝壳和小蟹的图鉴。

这里发布浏览器所需的编译成品。开发源码单独保存在私有仓库。第三方模型与字体的来源及许可说明随包附上。

GitHub Actions 从 `site-v11.1.zip` 部署。当前版本和校验值见 `release-manifest.json`。
