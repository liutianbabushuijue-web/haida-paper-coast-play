# 追潮记 · 拾光海岸

[进入海岸，直接体验](https://liutianbabushuijue-web.github.io/haida-paper-coast-play/)

无需登录 ChatGPT。支持电脑与手机浏览器，图鉴记录保存在各自浏览器中。

当前版本：**V16.1 · 2026-11-17**。

纸艺海岛、粉霞海面、天文大潮、可驾驶科考船、鱼蟹交互、追潮记图鉴与 CTD 教学模拟。本次修复船体随潮位升降，并优化画面运行与加载开销。

本仓库提供公开体验所需的编译运行包；开发源码单独保存在私有仓库，自有代码未授予开源许可。第三方素材遵循包内许可证。

为兼容现有部署流程，成品包仍使用 `site-v11.1.zip` 文件名；实际版本由包内 `release.json` 标记。GitHub Actions 会自动发布到上述地址。
